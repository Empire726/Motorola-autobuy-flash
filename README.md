# Motorola Stock Watcher v1.0

motorola.in ke liye (PayU payment).

## Flow
1. Product page: Add to cart (stock nahi → interval pe hard reload) → mini-cart "Go to checkout"
2. Shopping Bag: popup wali Quantity tak "+" → Checkout (out of stock → bag reload)
3. Checkout: popup ki details khaali fields me bharta hai → consent tick → Pay securely
4. PayU: Card (auto-fill) / Netbanking (bank) / EMI (bank + mahine + card) → Pay → alarm + Telegram → OTP aap daalo
